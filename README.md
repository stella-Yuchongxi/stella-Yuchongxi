## 我怎么做产品

- **先定义问题，再谈方案**：用户说要的是功能，我追的是他过去怎么做、愿不愿意付出、是不是一群人都会这样。
- **先收敛范围，再谈智能**：首页对话不必做成万能助手；企业 AI 不必另开一个聊天窗，能嵌进原流程就嵌进去。
- **先写清怎么验收，再谈效果**：没有上线数据时，写验收口径、阶段边界和下一步验证，不把目标写成结果。

## 经历

### 奇点求索 · 产品经理实习

`2026.08 — 至今` · 上海奇点求索智能科技有限公司

帮助用户生成、迭代和验证投资策略的 AI 平台，**产品尚未上线**。我负责用户调研、首页回答框架、信号源方案和会员门控设计。

- 产品初期缺少用户调研。我梳理需求文档后做了 2 次半结构化访谈，让用户还原真实投资过程：专业用户难执行既定规则，需要监控；新手缺从想法到可执行策略的路径。访谈结论按**待验证假设**处理，并在 PRD 里预埋后续埋点。
- 首页同一问题会出现两种回复形态。我将对话边界收敛为个股解读、宏观影响等 7 类问题，按「答案确定性 × 决策代价」收成 4 种回答模板，写入首页问答 PRD。
- 实时资讯建索引成本过高，且只有两类问题需要最新资讯。我设计用 Web Search 作临时通道，搜不到就隐藏资讯卡，失败则用弱分析兜底，避免空白页和编造。
- 原方案约 30% 因子免费，新用户很难第一次就创建有效策略。我推动把免费因子调到约 70%，目标是先拉高首次策略完成率；这是冷启动方案，**不是已验证的线上结果**。

### 博华信智 · API 与 Agent 开发实习

`2025.06 — 2025.09` · 北京博华信智科技有限公司

把 AI 嵌进售前工程师已经在用的业务系统，而不是做独立聊天窗口。

- **机泵选型 Workflow**：把人工「算数量 → 查规则选型号 → 汇总配置表」拆成可单独验收的三阶段；知识库放入售前总结的选型规则。主管用多份现场勘测表对照验收，**5 组样例的数量与型号字段全部一致**。售前反馈：原人工约 2–3 天的选型，AI 辅助可在分钟级出结果。这是验收与使用反馈，不是全场景准确率统计。
- **Odoo 系统集成**：报价和招投标仍要重复录入参数、整理清单和生成文档。我梳理 Odoo 与 Dify 的字段映射并开发 API，打通「提交业务数据 → AI 处理 → 回填或下载」。年终演示中，报价回填符合预期；招投标生成内容当时仍有优化空间。工作流由同事负责，我负责接口接入。

### 电商 AIGC 产品分析项目 · 产品分析助理

`2026.01 — 2026.02`

面向中小商家的营销素材生成方案设计，交付是需求、竞品、方案和验证设计，**没有上线业务结果**。

- 中小商家请不起专业制作团队，也难在批量活动里保持品牌视觉稳定。
- 对比 Midjourney、DALL·E、通义万相后，因批量场景下品牌一致性弱、闭源 API 难沉淀品牌资产，方案选择 Stable Diffusion + LoRA；文案侧用知识库约束卖点和品牌话术。
- 验证按「生成质量 → 生产效率 → 用户采用 → 业务效果」分层设计。质量不过先改生成和审核，不急着看转化；采用率低要区分模型问题和工作流过重。文中 85%、70%、CVR +5% 等数字都是**方案目标，不是实测**。

## 作品

### NutriTrace · 健康饮食习惯追踪 App

`2026.03 — 2026.06` · 悉尼大学可用性工程 · 课程优秀作品

[打开 Figma 原型](https://www.figma.com/design/L6owXwnaLjpPMuy4iNUi5w/Assignment-2-final?node-id=1-1)

小组项目。我参与需求分析、Figma 高保真和可用性测试。目标用户是已有健康饮食基础、但忙碌时难坚持记录的人。

- 用启发式评估、认知走查、Think-Aloud（5 人 / 10 项任务）和 SEQ / UMUX-Lite 问卷交叉验证。
- 多种方法都指向同一类问题：记录入口与编辑入口容易混淆，蔬菜份量换算困难。
- 第二版拉开记录 / 编辑按钮层级，并增加份量一键换算。能证明的是「发现问题 → 改设计」的闭环，不是上线后的留存数据。

### ClassPlus · 课堂互动平台

毕业设计 · 8 人小组

把「提升课堂互动」收成低门槛的双向反馈：老师在课件里发起投票和词云，学生用手机浏览器输课堂码加入，不用安装、不用注册。没听懂可点困惑；不想公开身份可匿名提问，但要过教师审核。

- 可用性测试：6 名参与者，教师端 + 学生端共 31 项任务。整体平均 SEQ 约 6.1；最低项是创建投票并设置正确答案，约 4.5。
- 发现不是功能不够，而是第一次找不到入口。如果继续做，会先改投票入口和模式提示，而不是加新互动。
- 这是课程原型，不是真实课堂长期上线。学校仓库在内网，对外以本页说明为准。
